# VDZ延伸意见处理与方案修订

本轮接受的方向是优先开展GSE73661中VDZ患者的内镜愈合关联延伸，暂停无边界的临床响应队列搜寻。此决策基于现有数据的可执行性及工作量，不宣称公共临床响应数据已经穷尽。GSE23597原主验证未达标的结论保留。

## 逐条处理

| 意见 | 判断与修订 |
|---|---|
| 用发现集效应0.599推算80%检出力所需规模 | 接受为条件情景。原始导出重算：正态近似72.41/128.55对，即向上取整73/129；使用相应自由度的非中心t近似为75/131。固定残差、响应比例、协变量结构并假定真效应为发现值，不能当作新数据入选硬门槛或未来结果预测。 |
| GSE23597加假想30对合并后检出力约49% | 接受该无条件、同精度外推情景，实际为49.43%。它不是给定已经观察到GSE23597结果后的预测成功概率；发现集效应也不是已知真值。 |
| 临床响应方向没有足够公共数据、再做约七成阴性 | 不接受为已核实事实。初筛非穷尽；没有事先指定未来效应/残差/设计或预测分布，不能给真实失败概率。接受目前优先处理现有VDZ数据的工作安排。 |
| VDZ评分此前从未计算 | 明确纠正。旧002B脚本先对全部178列计算5种评分，再截取IFX配对；support_scores.rds保存了113张VDZ芯片的评分。只对23对IFX做过已留存的结局模型。现有项目代码未发现VDZ患者级关联，但不据此证明没有任何历史或外部查看。 |
| VDZ使内镜证据基础大致翻倍 | 接受新增患者与药物背景的价值，删除证据强度翻倍。W6为27对、6愈合/21未愈合；W12另13对、3/10。W6愈合者少于IFX的8人，组别不均衡不能靠总样本数概括。 |
| vdz_plac W6保留 | 接受。3名W6患者均愈合；当次取样属于VDZ诱导，未来维持分配不作为基线协变量或排除理由。 |
| W12/W52与计划外取样 | W12作为不同患者的次要分析。W52及非核心时间点仅列取样清单，不能替代W6，不能推定持续VDZ或将不规则时间点重标成W6/W12。 |
| GSE16879应默认与GSE73661重复 | 接受独立性未确认前不使用的纳入规则；不接受同团队就视为已证实重复。优先原试验和样本来源核对，不用一般表达高相关补配。 |
| 基线队列对本问题无用 | 接受不用于当前delta评分验证；未来若研究基线预测须另设问题与验证，不能绕过当前锁定主张。 |
| VDZ阳性支持跨药物关联 | 接受为支持性观察，保留同一研究来源、构念重叠及时间/暴露差异，不升级为共同因果恢复机制。 |
| VDZ阴性界定为抗TNF特异 | 不接受。应写本VDZ队列/时间窗未获得跨药物支持。分开的显著/不显著不能证明效应有差异。 |

## 实施

原002C编号已经用于构念重叠诊断，本次添加002D_VDZ以避免覆盖。保留六基因、固定194基因炎症协变量及原评分方法；W6为一个主要支持性比较，W12为固定次要比较。报告调整基线和不调整基线等原有并列模型、OLS/HC3区间、所有患者影响诊断和留一患者分析，不据结果删患者。三个既有参考程序作为描述性比较，不宣称六基因优越。

分析性质为既有数据和既有全样本评分上的事后扩展；固定的是本次新的配对关联分析规则，不能写成数据访问前冻结或全新盲法验证。无论结果如何均保留于正文结果，不替代GSE23597，不合并其P值，不进行药物疗效排序。

## 实际执行结果

修订后的规则已在本次VDZ关联运行之前保存并冻结。该冻结仅证明项目内部的执行顺序，不是公开预注册，也不能消除之前已计算全样本评分的事实。

| 时间点 | 配对患者 | 愈合/未愈合 | 调整后β | 95%CI | 双侧名义P |
|---|---:|---:|---:|---|---:|
| W6，本阶段主要支持性比较 | 27 | 6/21 | 0.521263 | −0.435441～1.477967 | 0.271317 |
| W12，不同患者的次要比较 | 13 | 3/10 | 0.852753 | −0.385119～2.090624 | 0.153574 |

两行均为同一模型：delta_candidate ~ endoscopic_healing + baseline_candidate + delta_common194_inflammation，患者为统计单位。主要比较未达到预定的正向且P<0.05支持规则；两次估计均为正但区间较宽，不能证明效应为零、抗TNF特异性或两药效应不同。

并列结果也全部保留：

- 调整基线和炎症的HC3名义P：W6为0.091964，W12为0.173830。
- 不调整基线、保留炎症的OLS：W6 β=0.283859、P=0.474869；W12 β=0.824785、P=0.210358。
- 不调整炎症、保留基线的W6模型存在辅助名义阳性：β=1.020257；OLS P=0.066282，HC3 P=0.014509。该结果对协变量及标准误方法敏感，不替代本阶段的主要比较，也不能支持独立于炎症的增量。
- W6 OXPHOS参考程序名义P=0.017091，但三个程序乘两个时间点的六比较BH q=0.102544；不能由此声称OXPHOS优于六基因。
- W6留一患者估计范围0.414029～0.609971，P范围0.199093～0.432012；W12估计范围0.599594～1.198840，P范围0.049089～0.378341。保留所有患者；某次留一后显著不是排除该患者的理由。

本次结论：新增VDZ数据未建立明确的跨药物内镜愈合支持，亦未证明候选仅适用于抗TNF。文章继续如实区分发现、临床响应主验证、IFX内镜支持、VDZ范围检验及单细胞状态结果。当前宜结束这一有界扩展，进入正文证据组织，不通过改变时间点、删除协变量或患者来寻求替代主结果。
