# Publication figure layout revision

## Scope

The revision changed figure geometry and typography only. No input data, statistical model, estimate, confidence interval or P value was changed.

## Changes

- Figure 1 was rebuilt as a top-to-bottom study sequence with straight vertical arrows.
- Figure 2 now uses a dedicated blank GridSpec column between the forest plot and patient-level plot.
- Figure 3 now uses two dedicated blank GridSpec columns between its three panels.
- Figure 4 uses a wider canvas and 3.8-line facet spacing.
- Supplementary Figure S1 uses a wider canvas and 4.2-line facet spacing.
- Supplementary Figure S3 uses a dedicated blank GridSpec column; P-value labels remain inside their own panels.
- Supplementary Figure S2 is a single-panel figure and required no spacing change.

All revised figures were exported as vector PDF and 300-dpi PNG files. The complete BMC Genomics package passed all 35 automated package checks after regeneration. Visual inspection at reduced display size confirmed that panel titles, axis labels, annotations and legends do not enter adjacent panels.
