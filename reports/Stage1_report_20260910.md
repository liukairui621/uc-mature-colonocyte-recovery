## 已运行的统计比较

使用患者的治疗后减治疗前 log2 表达差值，通过 limma 分别估计药物组平均变化、安慰剂组平均变化以及两者之差。临床 response 分层为探索性关联对比；不能解释为基线预测能力或反应状态的因果作用。

主分支保留方案的配对分析。敏感性分支增加由 CEL 文件名推断的条码家族差值变量。该变量没有被原始元数据明确称为 batch 或 plate，报告中不把它写成已验证的技术批次。所有样本、探针处理和主要对比在两个分支相同。

|---|---:|---:|
| 药物组治疗前后 | 983 | 1224 |
| 安慰剂组治疗前后 | 0 | 0 |
| 药物变化减安慰剂变化 | 0 | 0 |

这里的零表示本次比较中没有单基因通过该多重校正阈值，不表示治疗无效、两组等效、所有转录变化不存在，或整个研究方向失败。药物组内有变化也不能替代药物与安慰剂的直接比较。

## 通路层面首先观察到了什么

使用 MSigDB Hallmark 2025.1.Hs 和固定版本的 GO BP 注释开展开放筛查；保留全部可测基因，不先筛差异基因再做通路检验。方法为 limma CAMERA 竞争性基因集检验，相关性参数固定为 0.01，基因集纳入范围为 15–500 个可测基因。报告每个库/比较内的 BH-FDR，同时另存四个比较合并校正结果。

以下属于**首轮探索观察**，还没有成为本文创新点或独立复现结论：

1. 药物组的 IFN-γ、IFN-α、炎症反应和 IL6/JAK/STAT3 相关转录变化偏向下降；主分支与条码敏感性分支方向一致。
2. 氧化磷酸化相关转录变化偏向上升，并在药物组应答者与不应答者的变化差异中出现。其细胞来源及与上皮成熟的关系尚未确定。
3. 安慰剂组也出现部分 IFN/炎症下降及代谢程序同向变化，因此上述结果不能直接称为戈利木单抗特异性。
4. 某些细胞周期/增殖相关药物—安慰剂对比对条码调整敏感。当前不把它们锁为核心机制。
5. 宽泛上皮相关条目仅提供后续检查入口。Hallmark APICAL_JUNCTION 含跨细胞区室基因，GO 也有跨组织命名，不能仅根据集合名称宣称肠上皮屏障恢复或损伤。

CAMERA 的 Up/Down 表示相对背景基因的协调性偏移，不等于直接测得的蛋白活性、屏障功能或绝对通路激活。表中 `mean_log2_change` 在组内比较中是平均前后变化，在组间/response 比较中是平均对比系数；它与 CAMERA 方向是不同概念。基因表 `AveExpr` 是配对差值的平均，不是原始表达均值。所有解释需要同时查看源基因和患者级变化，完整字段字典见 `runs/001B_discovery/contrast_dictionary.md`。

GO 成员表是在本次可测基因宇宙中构建，因此原 `GO_BP_coverage.tsv` 的比例不是全数据库通路覆盖率。已新增含正确范围标签的 `GO_BP_membership_scope_v2.tsv`；此次澄清不改变任何通路检验结果。Hallmark 原始 GMT 的完整成员覆盖率定义正常。

## 对原设计的影响

**主方向继续，具体创新对象尚未收敛。** 当前证据适合继续研究治疗背景下恢复状态及其与炎症、临床反应的关系；目前没有证实“上皮恢复与炎症缓解不同步”，也没有证明其独立于总体炎症。

下一阶段先在发现集建立患者级程序评分，将成熟上皮、应激再生、炎症和细胞组成分开解释。优先使用 UC 细胞状态标记与稳定模块细化，避免把通用 Hallmark 名称直接改成新 signature。保留主问题及共享恢复程序、应答相关状态两个备选解释，按患者稳定性和既有 MARS/IBrD 的关系收敛。具体候选产生后再做窄范围查新，固定程序及规则，随后使用独立队列验证。

这仍按务实发表定位执行：单次比较不显著不会终止整个方向；只有明确的重复结论或不可修复的方法问题才需要重构。当前也不增加与证据任务无关的分析模块。
